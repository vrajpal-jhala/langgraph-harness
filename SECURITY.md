# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Instead, use [GitHub's private vulnerability reporting](https://github.com/vrajpal-jhala/langgraph-harness/security/advisories/new) for this repo, or email the maintainer via the contact on the [GitHub profile](https://github.com/vrajpal-jhala).

Include what you found, how to reproduce it, and its impact. You should get a response within a few days.

## Scope

This project handles sensitive material by design — GitLab personal access tokens, OAuth client secrets, and `SECRETS_ENCRYPTION_KEY`. Reports involving credential handling, the encryption/decryption path, or the sandboxed agent's tool access are especially welcome.
